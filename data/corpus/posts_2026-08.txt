最近两周大模型有何最新进展？ 过去两周（约 2026 年 8 月 12–26 日），大模型领域的主线其实非常清晰：模型厂商正在从“更会答题”转向“能长时间自主完成真实工作”。Coding Agent、长程任务、强化学习环境、推理成本和多模态生产力，比单纯扩大参数规模更重要。 1. Gemini 3.7 Flash：性能继续涨，但“降成本”更值得注意 Google 在 8 月 13 日发布 Gemini 3.7 Flash，重点直接放在 coding 和 agents。Google 称它在软件工程、知识工作和 Web 开发工作流上都有明显提升，同时首发价格只有此前 Gemini 3.6 Flash 原始价格的一半。 这件事的意义不只是又多了一个更强模型，而是说明 frontier 模型的竞争正在出现第二条曲线： 能力 / 美元，而不仅仅是能力。 也就是说，2025 年大家还比较“谁 benchmark 第一”，现在越来越需要比较“完成一个真实任务到底花多少钱”。 2. Grok 4.6：长时间运行的 Agent 成为核心能力 xAI 在 8 月 12 日发布 Grok 4.6，官方对它的定位尤其值得注意：重点提升 long-running agents，让模型能够持续完成研究、信息分析、跨代码库操作以及从想法到完整应用/工作成果的多步骤任务。 训练方式也透露了行业方向：除了 SFT，xAI 大量使用 agentic RL，训练环境已经包括知识工作、通用编程、kernel optimization、Web 开发、CAD 等。 所以现在所谓“模型能力”，越来越接近： 理解任务 → 制订计划 → 调工具 → 执行 → 检查结果 → 修正 → 继续执行几十/几百步。 这和过去“一问一答”的 chatbot 已经是不同产品形态。 3. GLM-5.3：一个很重要的信号——不换底模，也能大幅变强 智谱 Z.ai 在 8 月 14 日发布 GLM-5.3。这是最近两周我认为技术上最值得关注的发布之一。 原因是 GLM-5.3 和 GLM-5.2 使用相同 base model，官方称提升全部来自 post-training 的扩展。 他们把强化学习环境扩展到更接近真实工程工作的任务，例如给 Agent 计算集群、存储、内部文档、代码库和实验结果，让它自己诊断训练系统瓶颈、修改代码、跑实验，然后验证最终性能是否提高。 结果是一些长程 coding benchmark 出现非常大的提升，例如官方报告： Terminal-Bench 3.0：4.6 → 28.3 DeepSWE v1.1：46.2 → 66.9 Agents' Last Exam：23.8 → 28.5 而且长程 RL 训练系统吞吐量提升超过 2.3×。 这背后是一个很重要的判断： 下一阶段模型进步可能越来越多来自“环境 + RL + verifier + synthetic trajectories”，而不是单纯预训练规模。 换句话说，“怎么教模型工作”开始和“模型本身多大”一样重要。 4. Qwen：百万级上下文 + 原生视觉语言模型继续下沉 Qwen 最近的新型号中，Qwen3.8-27B 很有代表性。Alibaba Cloud 的资料显示，它是一个 27B 的原生 vision-language dense model，重点增强 coding 和 office productivity，同时支持图像、文本和视频输入。 更值得注意的是 context： 最大输入约 99 万 token，最大输出 131K token。 这意味着“百万上下文”已经越来越不像旗舰模型独占的实验特性，而是在往更小、更便宜、更容易部署的模型层级扩散。 Qwen Code 本身也在快速 Agent 化。例如 8 月 20 日的更新加入 /advisor，可以让一个独立 Agent 对当前工作给出第二意见，包括结论、风险、缺失证据和建议。 5. Anthropic 最近两周没有新旗舰 Claude，但出现了另一个重要变化：AI 文本水印 Anthropic 最近的旗舰模型发布仍是 7 月 24 日的 Claude Opus 5，所以严格按照最近两周，并没有新的 Claude frontier model。 但 8 月 14 日 Anthropic 公布了 Claude 的文本 watermark 机制，并表示未来 Claude 模型生成的文本会包含这种水印，以满足 EU AI Act 相关要求。 比较有意思的是，这不是插入隐藏字符，而是利用生成文本时的概率选择形成统计信号；Anthropic 表示它不包含个人身份信息，也不会增加 token 成本。 这说明模型竞争已经出现一个新的维度： 不仅要训练模型，还要解决“互联网如何识别 AI 生成内容”的基础设施问题。 6. OpenAI 最近两周最大的动作反而在模型下面：推理芯片 OpenAI 最近两周没有发布新的通用旗舰模型；当前 ChatGPT 旗舰 reasoning model 的重要发布仍是此前的 GPT-5.6 Sol。 但 8 月 25 日 OpenAI 公布了自研推理芯片 Jalapeño 的首批实测结果。OpenAI 表示，在使用 GPT-OSS 120B 的 InferenceX 测试中，它获得了更高的单位功耗峰值吞吐量和更低 token latency，并且在 DeepSeek R1、Kimi K2 上也有类似收益。 这个发展很容易被模型发布新闻掩盖，但长期可能更重要。 因为现在 frontier AI 的竞争正在变成： 芯片 → 数据中心 → inference stack → 模型 → Agent → 产品 的全栈竞争，而不是只训练一个 LLM。
